# WoundFrame Changelog

## 1.0.0

Initial public-ready release.

- manual three-click image calibration;
- physical-scale normalization;
- fixed physical crop around the wound center;
- optional generated scale bar;
- automatic timepoint detection;
- disorganized-folder and ZIP input;
- subject × timepoint panel generation;
- configurable panel spacing;
- persistent calibration;
- SHA-256 input manifest;
- settings-specific run directories;
- processing metadata and environment-version recording;
- duplicate and unparsed-file reporting;
- Windows launcher with fast defaults.
